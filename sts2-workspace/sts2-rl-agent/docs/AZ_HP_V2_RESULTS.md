# Reward v2 实验结果

**结论：40 HP / starter / Shrinker 限定模拟任务通过当前 spec v0.2 的工程与学习验收。** 两个 seed 的网络直接决策和同预算搜索均相对各自初始模型改善。此结论不代表胜过规则策略，也不证明改用 v2 奖励本身是改善的原因。

## 实际范围

Seeds 42、43 各训练两轮，共 1,024 个完整训练 episode、800 次更新；每轮 512 个验证场景。两组均连续两轮晋级，最终都是各自的 candidate-1.pt。全部最终模型先冻结，再评估同一组 500 个新测试场景。两个训练 seed 不等于 1,000 个不同测试场景。训练预算 64 simulations，搜索评估预算固定 256。奖励为 win-first-hp-v2。

## 胜率与奖励

胜率差 CI 是固定统计 seed 1729、10,000 次成对 bootstrap，单位为百分点。奖励差独立计算，没有以 v2 奖励差除以 2 冒充胜率差。

| Seed | 模式 | 初始胜率 | 最终胜率 | 胜率增益 95% CI | 效用增益 95% CI |
|---:|---|---:|---:|---:|---:|
| 42 | 网络直接决策 | 84.4%（422/500） | 100%（500/500） | +12.4 ～ +18.8 | +0.2912 ～ +0.4009 |
| 42 | 网络 + 搜索 | 90.0%（450/500） | 100%（500/500） | +7.4 ～ +12.6 | +0.1912 ～ +0.2815 |
| 43 | 网络直接决策 | 31.6%（158/500） | 100%（500/500） | +64.2 ～ +72.4 | +1.2028 ～ +1.3437 |
| 43 | 网络 + 搜索 | 86.6%（433/500） | 100%（500/500） | +10.6 ～ +16.4 | +0.2588 ～ +0.3578 |

四项的胜率和效用增益 CI 下界都严格为正，符合预先固定的验收门槛。所有记录的最终场次无模拟器异常、非法动作或超限；日志中两次 Windows 原子替换冲突均在一次重试后恢复，未造成轮次失败。

## 保血与基线：仍存在差距

| 策略 | 测试胜率 | 最终平均剩余 HP（40 HP 开局） |
|---|---:|---:|
| 随机合法策略 | 59.4% | 7.738 |
| 固定公开规则 | 100% | 32.114 |
| Seed 42 网络直接决策 | 100% | 31.780 |
| Seed 42 网络 + 搜索 | 100% | 27.138 |
| Seed 43 网络直接决策 | 100% | 31.884 |
| Seed 43 网络 + 搜索 | 100% | 27.244 |

平均 HP 包含所有场次；随机策略死亡计零，其余策略全部获胜。最终网络接近规则策略，但没有超过它。搜索比同一最终网络直接决策平均少保留约 4.64 HP，两组 seed 均如此；胜率相同，所以搜索在这批场景上的 v2 效用也更低。

事后配对诊断：搜索减网络的 HP 差 CI，seed 42 为 [-5.174, -4.114]，seed 43 为 [-5.160, -4.120]；网络减规则分别为 [-0.552, -0.124] 和 [-0.396, -0.090]。这些是发现结果后的诊断，不参与已结束实验的模型选择或预设晋级门槛。详情见 [az_hp_v2_hp_diagnostics.json](az_hp_v2_hp_diagnostics.json)。

旧全状态 MCTS oracle 仅在 16 个 validation 场景上 16/16 胜、平均剩余 29.3125 HP；信息权限和场景集合不同，不能与上述 500 场结果混排。

## 可用模型与后续方向

冻结的模型分别为：

- `output/az_hp_v2_experiment/seed-42/candidate-1.pt`
- `output/az_hp_v2_experiment/seed-43/candidate-1.pt`

暂不根据最终测试中的细小差距选出唯一优胜 seed。当前最值得研究的是为何搜索降低保血：在新的训练／验证局面上比较网络、搜索动作与后续实测结果，检查 value 估计、根访问分配和预算影响；任何调整后应使用新的未见测试集。当前测试集已用于结果观察，不可继续当作独立调参验收集。

本轮同时改变了难度、奖励和 v2 编码器维度，且没有同难度 v1 对照。可以说明“本次模型训练后改善”，不能据此单独归因于新的奖励计算。下一次消融应在相同难度、模型结构、训练预算与 seed 下比较奖励方案。
