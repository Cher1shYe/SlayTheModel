# A0 Ironclad coverage manifest

Contract: STS2 v0.111.0, standard single player, all content unlocked, Ironclad, Ascension 0, single run from the opening Ancient to the act-3 boss. Status meanings: **IMPLEMENTED** (reachable and behaviorally handled), **APPROXIMATE** (reachable, but a UI/choice or secondary effect is substituted; see notes), **UNSUPPORTED** (not reachable in this contract or deliberately excluded; the engine refuses to draw these from the run bags).

Generated by `simulator/tools/gen_coverage.py`; do not hand-edit the tables. The C++ side of this manifest is the event table in `simulator/src/events.cpp` plus `relic_implemented()`; regression tests assert that unsupported entries never enter a bag.

## Cross-cutting approximations

- Event card/discovery choices use deterministic RNG picks instead of a card-selection UI; enchantments `Sown`/`Vigorous` are substituted by random upgrades and `Metamorphosis` by a random colorless card.
- Curses are absent outside combat, so cursed-relic and event curse effects only apply their non-curse halves.
- Some event relics needing enchantments, pets, or map manipulation are no-ops or substitutes; the originating events are marked APPROXIMATE.
- Potion rewards are auto-added when a slot is free; boss relic and non-card rewards are auto-collected.
- Combat rewards use independent simplified draw bags; the exact tagged GrabBag ordering is approximated by act-filtered lists.
- Multiplayer/ally-targeted effects are no-ops or applied to the player; card text is never parsed, semantics follow the reference effect code.

## Differential status

Golden tests cover map topology hashes, run determinism, snapshot/restore, room/economy structure and full A0 wins. A byte-for-byte headless-client differential trace is not available in this environment; areas not covered by golden traces are listed above as APPROXIMATE/UNSUPPORTED rather than claimed exact.
