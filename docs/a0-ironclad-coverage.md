# A0 Ironclad coverage manifest

Contract: STS2 v0.111.0, standard single player, all content unlocked, Ironclad, Ascension 0, single run from the opening Ancient to the act-3 boss.

Status vocabulary: **EXECUTABLE** (data + engine can drive it; effect not individually asserted), **EFFECT_TESTED** (a semantic test asserts its behaviour), **APPROXIMATE** (reachable but a UI/choice or secondary effect is substituted), **UNSUPPORTED** (not reachable or deliberately excluded; the engine refuses to draw it). **Reference-validated** (step-by-step differential against a client trace) is not claimed for any item: no headless client trace is available in this environment.

## Cross-cutting approximations

- Event card/discovery choices use deterministic RNG picks instead of a card-selection UI; enchantments `Sown`/`Vigorous` are substituted by random upgrades and `Metamorphosis` by a random colorless card.
- Curses are absent outside combat, so cursed-relic and event curse effects only apply their non-curse halves.
- Some event relics needing enchantments, pets, or map manipulation are no-ops or substitutes; the originating events are marked APPROXIMATE.
- Potion rewards are auto-added when a slot is free; boss relic and non-card rewards are auto-collected.
- Combat rewards use independent simplified draw bags; the exact tagged GrabBag ordering is approximated by act-filtered lists.
- Multiplayer/ally-targeted effects are no-ops or applied to the player; card text is never parsed, semantics follow the reference effect code.
- Encounter roster weights are empirical frequencies over 512 seeds, not symbolic probabilities; rare variants could still be missing.
- Monster move effects are recorded from one execution at the initial state. Moves whose values change while the fight progresses (Test Subject multi-claw, Knowledge Demon curse counter, Frog Knight charge) are special-cased and tested; other dynamic effects may remain at their first recorded value.

## Differential status

Golden tests cover map topology hashes, run determinism, snapshot/restore, room/economy structure and full A0 wins. A byte-for-byte headless-client differential trace is not available in this environment. No item is therefore marked reference-validated; items without a semantic test are EXECUTABLE only.
