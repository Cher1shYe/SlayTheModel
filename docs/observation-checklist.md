# 观察清单：AlphaDefect 有什么、我们有什么、可以多加什么（2026-11-18，Claude）

来源：AlphaDefect 的 `docs/replay-format.md`（本机 `artifacts/reference/alphadefect-evaluation-overview/`）；我们的 `sim/src/combat_obs.cpp`（战斗）和 `sim/src/macro_obs.cpp`（局外；`train/spire_rl/obs.py` 在战斗里也带着它，作为“局外上下文”）。

注意：AlphaDefect 的记录只是观察的摘要，它自己说“网络还收到了这里没写出来的特征”。所以下面“它有”的是下限。

标记：✓ 有；~ 部分有；✗ 没有。

## 0. 先说清楚“比它多”指什么

NoSL 的前提下，网络能看的信息**不能多于人能看到的**。所以“多”不是多看秘密，而是：

1. **把人能看到的都给全**：它有的我们一项不缺。
2. **多给“算好的结论”**：人能用规则和公开信息算出来、但网络自己要学很久才会算的东西，由引擎直接算好给它。例如“打这张牌给这个敌人会打掉多少血、能不能打死”。这能省掉大量训练量。
3. **用我们的模拟器做公开信息下的预演**：我们已有 `resample_hidden`（把抽牌顺序和战斗随机数流换成随机重排，只保留公开信息）。在重排后的局面上试走一步，取平均结果，就是“只用公开信息能预期的效果”，不泄露真实的隐藏状态。AlphaDefect 说自己不用求解器，我们可以在这上面多做。

真正拉开差距的，最终还是训练量和训练方法；观察只是让同样的训练量学得更快、上限更高。

## 6. 我们可以多加的（建议按优先级）

**A. 先补齐它有的**（必须做）

1. 手牌显示的伤害和格挡（算上修正）。
2. 怪物招式 ID、后续最多 3 步的招式预测。
3. 每个敌人“这回合最多还能打它多少 / 能不能打死”。
4. “现在结束回合会掉多少血”补全：自伤、回合末格挡、多目标随机的情况。
5. 路线摘要。
6. 遗物状态补全；事件选项提示里的物品；选择界面的用途和来源；苦难。

**B. 每个动作的“效果预览”**（它没有，我认为最值钱）

动作已经指向“哪张牌 → 哪个敌人”。给每个候选动作加一行数字：

- 对目标打掉多少血（算上易伤、格挡）、会不会打死；
- 得到多少格挡；打完之后“结束回合会掉多少血”变成多少；
- 花多少能量，打完剩多少。

算法：在 `resample_hidden` 重排过的局面副本上实际走这一步，取几次平均。只用公开信息，NoSL 安全。代价是每个决策要多跑几次模拟器单步（每步约 4 微秒，几十个候选也只是零点几毫秒）。

**C. 抽牌概率**（人能算，网络很难学）

抽牌堆里攻击、技能、能力、状态牌各多少张；下回合抽到某类牌的概率；还有几张会洗牌。

**D. 本幕已遇到的遭遇**

人记得本幕打过哪些怪、精英还剩哪些可能。游戏开头几场是弱怪池，之后是强怪池。这些是公开的历史，它的记录里没有。

**E. 牌组摘要**（帮助选牌）

攻击、技能、能力、诅咒张数，平均费用，总伤害/总格挡密度，升级比例。网络能从牌组记号自己算，但给出来能学得快一些。

**F. 一回合规划的上限**（可选，代价高）

“本回合最多能叠多少格挡”“最少会掉多少血”“最多能打多少总伤害”。需要在手牌上做小搜索，算起来慢，先不做，等 B 的效果出来再说。

## 7. 灰色地带（需要用户定）

| 项目 | 为什么是灰色 | 建议 |
| --- | --- | --- |
| 招式预测的**概率** | 界面不显示，但出招规则是固定的，熟练玩家凭经验知道；AlphaDefect 也给了 | 给 |
| 卡牌稀有度保底计数（`cardRarityOdds`） | 界面不显示，但完全由见过的牌决定：起点 −5%，普通战斗奖励每出一张非稀有牌 +1%（A7 起 +0.5%），上限 40%，出稀有牌或 Boss 奖励后回到 −5%；普通战斗稀有率 = 3%（A7 起 1.49%）+ 它，精英 10%（5%）+ 它，商店 9%（4.5%）+ 它。记着每次奖励的人能算出来 | **改为可以给**（11-18）：它是公开历史的总结，不是隐藏随机数；影响小，优先级低 |
| 事件各选项的结果 | 有的选项结果写在文字里（公开），有的随机（隐藏） | 只给文字里写明的物品和数值（**用户 11-18 同意**） |
| 敌人的真实下一招（当意图是随机的） | 隐藏 | 不给策略；只给价值函数（若采用） |
| 抽牌堆真实顺序 | 隐藏 | 同上 |

## 8. 其他从它的记录里看到、不属于观察的

- **防卡死**：敌人血量合计连续 20 个玩家回合没创新低判负；一回合内反复回到同一局面就强制结束回合。
- **相同的牌分成不同选项**：两张打击是两个选项，概率各一半。我们也是按手牌位置给选项，一样。
- **只有一个选项的界面**：它也记成决策；我们自动执行。不影响观察。
