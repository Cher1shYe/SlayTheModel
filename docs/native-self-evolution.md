# Native MCTS 小范围策略自进化

## 使用范围

原生 C# 完整信息搜索产生策略标签，Python 沿用旧工程的 XS Transformer 和
Learner 更新策略。Python 不模拟战斗、不读取旧的 observable replay buffer。
当前仅支持 BYRDONIS_ELITE、未升级的初始打击/防御/痛击，无遗物和药水。
模型观察仍是公开特征，搜索使用真实牌序和 RNG；这是完整信息教师指导公开观察策略，
不能当成可观察信息搜索的实验，也不能推出全游戏性能。

启动命令（Windows，本地 CPU）：

```powershell
& '<sts2-rl-agent>/.venv-az/Scripts/python.exe' scripts/native_evolution.py `
  --source '<sts2-rl-agent>' --game '<Slay the Spire 2>' `
  --checkpoint '<frozen_model.pt>' --output 'artifacts/native-evolution-new' --build
```

游戏合同为 Windows v0.111.0，依赖与普通 native-worker 相同。无需 Steam 可见会话。
模型、训练数据、优化器与日志保存在 output 中；不覆盖旧工程或玩家默认模型。
已有相同 worker 产物时省略 `--build`。

## 固定实验协议

- 两轮，每轮 100 场；训练种子分别 101–200、201–300。
- 初始 HP 按 50/60/70/80 循环，最大 HP 为该初始角色固定的 80。
- 训练采用学习先验 PUCT，每决策 100 ms，前两回合按访问次数分布抽样执行。
- 验证种子 1001–1012，每轮候选与当前冠军分别测试搜索和纯策略。搜索均为 100 ms；纯策略取最大概率合法动作。
- 晋升只看搜索：胜场不能减少，且平均终局效用提高超过 0.005。纯策略作为独立诊断，不参与此次晋升条件。
- 最终测试种子 2001–2012，仅在两轮训练、晋升结束后打开；比较初始、两个候选的搜索与纯策略，以及均匀先验 PUCT。
- 100 次 AdamW 更新/轮，batch=32，microbatch=16，学习率 0.0003，梯度范数上限 1。
- 第二轮训练复用两轮采样，模型从当前冠军开始；每轮重置优化器。价值损失权重为 0，value head 参数冻结且不参与搜索；共享特征仍会改变其输出，因此不能把 value 输出当作经过本轮校准的价值估计。

每个原生 worker 最多处理 8 场，120 秒超时。每场先预热推理及 300 ms 搜索（纯策略无搜索预热）。
每个实际动作检查非终局的 native/simulation continuation。未完成战斗显式失败，不冒充死亡标签。

## 数据与模型合同

`native-evolution-v1` 单独保存原生决策前观察、完整合法动作、根访问概率（包括零访问动作）、
执行动作、访问次数、种子、初始 HP、模型 SHA256、终局与耗时。
训练前核验动作集合、合法执行动作、访问次数及概率和。
共享的 `native_prior_features.py` 为训练和推理提供同一特征投影。

策略目标为根访问分布。终局收益仅记录：胜利 `0.9+0.1*(最终HP/80)`，死亡 `-1`。
这次不使用终局收益训练价值，也不把 rollout 中间截断奖励当作整局标签。
搜索内部仍使用已有 native 奖励。

为了复用旧网络结构，张量/权重容器保留原 ALL/V7 元数据；新增的
`run_config.native_evolution` 明确记录原生数据来源、信息模式和 policy-only 训练约定。
它不是旧 V7 自进化实验的续跑，不能将这些数据混入旧 replay。

## 保存、恢复与晋升

启动即保存配置、初始权重副本和 Python 依赖源码指纹。恢复时配置和源码必须一致。
每个原生批次写临时文件后原子替换；完整批次校验模型指纹及种子后复用。
部分批次会重跑该批，不重复追加样本。训练候选原子保存，包含最终优化器和采样 RNG。
中途训练未保存候选时，从该轮起点重新训练；不是逐更新的精确恢复。
已完成候选校验父模型和配置后直接评估。

`round-1.json`、`round-2.json` 保存晋升证据；`result.json` 保存最终冠军与所有测试汇总。
不合格候选仍保留用于审计，不自动部署到玩家会话。

这是小样本、单遭遇试验。固定时间预算会受到 JIT、GC 和调度影响；即使测试指标提高，
也只说明这组场景的观察结果，不是全怪物泛化或统计显著性结论。
