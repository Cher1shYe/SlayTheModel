# MCTS 失败与未完成路线的进度奖励

2026-10-15，游戏 v0.111.0，本地修改与部署。本文按用户最新澄清更新；此前“排除所有附属怪”的解释和实现已撤回。

## 评分口径

女王 400 HP 与开场仆从 199 HP 应一起计分。需要避免的是同一怪物复活后把上一条生命损失再次累加，不是排除所有仆从。

对搜索根捕获的敌人集合，令：

`p = (Σ捕获时最大血量 - Σ模拟末尾剩余血量) / Σ捕获时最大血量`

每个身份的剩余血量限制在 [0, 捕获时最大血量]。普通死亡为 0；复活或治疗后使用恢复后的血量，所以之前的缺血奖励会减少。同一怪打死两次而最终状态相同，p 也相同。仆从、主怪以及仍在战斗阵容中但暂时为 0 HP、等待复活的怪都计入。永久死亡后从阵容移除的捕获对象仍保留身份，避免击杀进度丢失。

| 模拟结果 | 奖励 |
| --- | --- |
| 胜利且存活 | 原公式 `0.5 + atan((playerHp - entryHp) / 20) / π` |
| 玩家死亡 | `-1 + 0.49 × p` |
| 存活但未完成 | `-0.255 + 0.245 × (p - l)` |

2026-10-16 更新：`l = clamp((entryHp - playerHp) / entryHp, 0, 1)`，以入战血量为分母计算自身最终净损血比例，入战血量必须为正。回血抵消惩罚，超过入战血量不额外奖励；不累计中途受到的伤害。敌我损血比例等权，未完成区间仍为 [-0.5, -0.01]，保持胜利 > 存活未完成 > 死亡的单次结果顺序。此顺序不等同于对 MCTS 分支均值做字典序排序。

本次 ReplaySearch smoke 验证选择“敌方损血 40%、自身无损”优于“敌方损血 50%、自身损血 50%”，并覆盖回血、比例归一化和原有胜负顺序。原生验证日志见 `artifacts/verification/mcts-player-loss-20261016.txt`；远端 ae612c3 的采集来源更新验证日志见 `artifacts/verification/collector-policy-20261016.txt`。

ReplayMcts 只在一条模拟结束或达到深度上限后计算一次 value，再将这个同一个 value 回传给访问节点。没有中途伤害累计，也不把每一步的损血比例相加。超时／取消中断的半条模拟仍不回传。

集合与最大血量基准在 Capture 时冻结，Restore 和 Promote 不改分母。模拟中途新增身份的怪，在下一次完整 Capture 时加入基准；这保持原有固定集合约定，并非对所有未来召唤、分裂阶段总血量的预估。此边界还未穷举验证所有遭遇。不能把 p=1 当作获胜，胜负仍由引擎判定。

## 本轮验证

`scripts/native-worker.ps1 -GameDir <游戏目录> -Mode reward-verify` 构建与验证通过：

- 女王与开场仆从总血量为 599。攻击两者都增加末尾缺血比例；仆从死亡移出阵容后仍只计算一份血量。
- OVICOPTER_NORMAL、FOGMOG_NORMAL、FABRICATOR_NORMAL 实际召唤后捕获新根，召唤物均按末尾缺血比例计入，重新捕获不排除附属怪。
- FOGMOG_NORMAL 的利齿之眼死亡后，在 0 HP 等待复活时重新捕获根，再推进原生回合使其复活；奖励随回血减少。第二次击杀比例仍为 0.075，与第一次相同，不变为 0.15。每个步骤都核对预测／原生完整 continuation key。
- CULTISTS_NORMAL、KAISER_CRAB_BOSS、QUEEN_BOSS 同根短搜回归通过。女王的 8 点伤害对应 8/599，而不是 8/400。
- 日志：`artifacts/verification/mcts-endpoint-reward-20261015.txt`（不入 Git）。

之前排除附属怪版本的测试日志只证明旧规则的实现，不代表用户希望的规则，已由本轮测试替代。未声称所有怪物、分裂、换阶段或第三方 Mod 都已穷举验证，也未声称整局胜率提高。

## 使用
