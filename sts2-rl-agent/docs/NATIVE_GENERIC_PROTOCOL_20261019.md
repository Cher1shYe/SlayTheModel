# 通用原生采集协议（2026-10-19）

本文保留通用桥接初版的验收记录。后续已接入手写／学习／混合价值三种原生搜索模式，见 [价值叶子说明](NATIVE_VALUE_MCTS_20261019.md)；以下 rollout 描述对应初版默认 heuristic。

## 数据路径

原生建局 → 现有 `CombatCaptureService.BuildObservation` → 原生合法动作候选 → C# `ReplayMcts` → 原子落盘的整场轨迹 → `GenericReplay` → Transformer 策略／价值更新 → 独立冻结验证 → 冠军门禁。

Python 不再根据卡名查 `expanded_entities.card_entity`，不实现卡牌或怪物结算，也没有逐卡准入表。`protocol.json` 中的牌和遭遇 ID 只是课程抽样数据；增加原生引擎已支持的内容只需修改清单并重新冻结验证集。不存在的原生 ID、模拟器未支持的机制、状态／动作不一致仍会明确失败，不跳过候选或把失败标成死亡。

## 模型与协议

- 轨迹：`native-generic-collection-v1`；观察：`native-generic-observation-v1`；模型内容：`native-generic-json-v1`。
- 原生观察包含玩家资源、角色、生命／格挡／状态效果、各牌堆、费用、升级、关键词、附魔／污染、动态变量、敌方可见意图和选牌选项。合法动作按当前候选逐项评分，支持出牌／目标／结束回合／选牌组合，无固定卡牌动作词表。
- 通用字段／类别使用两个确定性哈希嵌入，数值使用带符号 log1p；实体经过 Transformer，候选通过交叉注意力得到策略分布，状态池化得到价值。哈希存在碰撞可能；这是可扩展编码，不代表模型天然理解未见过的卡牌效果。
- 不把 RNG、原生检查点或动作 Key 喂给网络；抽牌堆按公开属性排序，消除隐藏抽牌顺序。动作 Key 仅用于对齐概率、访问次数及执行动作。未知顶层协议扩展明确拒绝，防止静默遗漏特征；当前未接入同伴、排队手动操作等扩展。
- 新模型、旧实体模型的 checkpoint／replay 契约隔离，不能直接加载旧权重。旧后端与旧训练产物保留。

## 搜索与训练机制

当前是 `root-prior-uniform-tree-rollout-v1`：每个真实决策使用当前学习者提供根先验，树内使用均匀先验和 C# rollout／手写截断评分。价值头有训练目标，但**尚未用于此原生搜索的叶子估值**。教师可使用原生检查点完整信息，学生使用公开观察；不是完整信息完全一致的 AlphaZero。

搜索预算单位为毫秒，不是模拟次数。示例配置采用每决策 1000 ms；100 ms 在本机首次扩展时曾无法完成有效 rollout，零访问标签会拒绝入库。真实决策最多 100 次／40 回合，超出即失败，不伪造终局奖励。验证使用纯网络，不能把它的成绩解释为 MCTS 强度。

保持 `all_runner` 的持续学习者、独立冠军、配对 bootstrap 晋级规则、优化器／采样 RNG／Torch RNG 的逐更新恢复。已完成对局原子缓存并按遭遇分层回放；失败后仅补缺失整场。未完成的单场仍需重跑，尚无任意战斗中间点恢复。缓存绑定模型、协议、源码及配方摘要，变更来源后要求新目录。

## 一致性检查

每个普通决策根及非终局普通后继比较完整 continuation；挂起选择比较选择合同及合法候选覆盖，选择结束后恢复完整 continuation 比较。终局检查胜负、HP 和 V7 奖励，不声称终局清理后的全部内部状态一致。校验访问次数总和、候选 Key、一致的选择身份、初始卡组／升级、HP 连续性、有限数值、样本摘要及训练／验证隔离。

合法选择按集合比较覆盖，导出和执行仍保留实际选择顺序。原生自动解决的唯一选择在模拟端自动续接后继续完整比较；不替用户处理有多个合法结果的决策。

## 有界工程验收入口

```powershell
.\.venv-az\Scripts\python.exe scripts/check_native_generic.py --out output/native_generic_check --smoke-update
# 来源与配置未变时，复用已完成对局；不再次进行更新：
.\.venv-az\Scripts\python.exe scripts/check_native_generic.py --out output/native_generic_check --resume
```

配置及独立冻结验证集位于 `configs/az_native_generic_v1/`。入口只采集 4 场、验证 8 场，`--smoke-update` 只做两步工程更新及精确恢复断言，不启动正式训练。当前配置是接线示例，不是下一轮正式训练的推荐参数。

## 本轮验证结果

最终产物：`output/native_generic_verified_20261019/first-run-report.json`、`resume-check.json`。4 场 PUCT 采集 + 8 场纯网络验证，共 162 个决策检查；其中 5 个显式选择决策、2 次自动唯一选择续接，最多 3 个敌人。训练回放 71 行，两步工程更新的 loss 均有限，优化器／采样 RNG／Torch RNG 恢复后的权重与连续更新完全相同，冠军 `initial.pt` 不变。验证为初始随机网络的 4/8 胜，不能作为学习增益证据。

12 场实际缓存续跑退出码 0，22 个缓存／日志／checkpoint 文件内容和修改时间保持不变。110 项 Python 测试通过（109 项适配及旧路径回归，加 1 项通用采集失败续采／来源变更拒绝测试）；C# ReplaySearch smoke 通过。故障注入覆盖基线验证、第二轮更新、候选验证：恢复不重采已提交数据，持续学习者仍用于下一轮采集，未晋级冠军仍保留。

保存的 `tests/fixtures/native_generic_v1.json.gz` 来自同协议上一轮有界验收，含四个遭遇的真实完整训练侧轨迹。测试覆盖未注册内容的编码、隐藏抽牌顺序／opaque Key 不进入模型、候选重排等变、无效选择／目标／访问次数／奖励／初始升级拒绝，以及旧 checkpoint／replay 不兼容。

修复了跨角色 Power 列表排序误报、选择集合排列误报、原生自动唯一选择与模拟选择节点的边界差异，并将采集模组和共享 DTO 源码加入缓存来源摘要。源码或协议变化后不强行复用旧缓存。

没有启动正式训练、打开测试集或部署 Mod。少量内容通过不等于全部卡牌、全部遭遇或第三方 Mod 已得到验证。
