# T4 value 权重与搜索预算消融总结

实验于 2026-10-17 15:06（北京时间）完成；未启动正式训练。独立证据复核已通过：三组共 1,080 条 Replay 记录、12 个更新 checkpoint、抽样与 network 验收统计均核对通过，详见 independent_audit.json。

## 对照结果

固定同一第一轮冠军、seed 41、第二轮四次更新、3:1 课程、batch 64/microbatch 8 和 256 场纯 network 验证。

| 组 | value loss 权重 | 新轨迹 MCTS 预算 | network 效用 | 相对失败基线提升 | 提升的 95% CI |
|---|---:|---:|---:|---:|---|
| 原第二轮 control | 1 | 8 | 0.152759 | — | — |
| 降低 value 权重 | 0.1 | 8 | 0.235308 | +0.082549 | [0.044956, 0.120557] |
| 增加搜索预算 | 1 | 32 | 0.237246 | +0.084487 | [0.046894, 0.122452] |

两项单因素干预均通过相对失败候选的既有 network 效用改善门槛。第一轮冠军为 0.252700，两组仍未超过冠军：分别差 -0.017393（CI [-0.047363, 0.012354]）和 -0.015454（CI [-0.045401, 0.014277]）。区间跨零，不能据此宣称两组显著劣于冠军，也不能宣称超越或等效。保留第一轮冠军。

搜索 32 相对 value 0.1 的差为 +0.001938，配对区间 [0.001606, 0.002261]；在当前探索性验证上为正，但幅度很小。逐场终局分类完全相同（161 对 win/win、95 对 death/death）；44 场效用不同，来自获胜时剩余 HP，而非多赢对局。验收依据仍是效用，胜负数字仅解释差异来源。

## 改善来自哪里

两组都将力量构筑 × Bygone Effigy 的效用从 -0.132406 拉回 0.405250，但仍低于第一轮冠军的 0.504312。

格挡 × Bygone Effigy：value 0.1 组为 0.961359，搜索 32 组为 0.972147；其差异是两种消融整体表现差别的主要来源。Boss 验证共 84 场，两组仍全为 -1。此次没有证明自然后期可解性得到改善。

这支持两个判断：降低共享 value 学习的权重能缓解退步；增加采集搜索预算也能缓解退步。它们都不是完整解决方案。两种干预的效果是否可叠加、是否有交互，尚未测量，不能把两项增益相加。

## 可比性与校验

- control 的四次更新从相同起点重新计算，模型与 AdamW 状态逐项复现原第二轮。
- value 组全部 Replay、四个 batch 的内容与 control 一致，只改变 loss 系数。
- 搜索组只重采第二轮的 180 条（135 整场、45 后期）；第一轮历史 180 条保留 8 次搜索标签，所有环境/搜索 seed 与配方沿用。

## 下一步建议

1. 不进入正式训练，保留第一轮冠军。两项消融都没有达到超越冠军的效用门槛，Boss 也未改善。
2. 优先把 value=0.1 作为下一阶段候选：当前改善幅度接近 search=32，且不增加每个决策的采集搜索次数。这是本地成本与收益判断，不是多 seed 优越性结论。
3. 若继续授权实验，补齐 value=0.1、search=32 的组合组，完成同一起点的 2×2 因子对照；用它检验交互，不预设叠加有效。先保持相同四次更新与验收条件。
4. 再对选定配置进行多个 seed 的短程确认。当前仅 seed 41，且验证集已经被反复用于诊断；最终质量仍需独立留出，不能把这次区间当作通用性证据。
5. Boss 单独继续审计搜索标签质量和成功轨迹覆盖。仅提高预算或降低 value 权重，没有让现有 network 通过 Boss。

以上仅建议，没有自动启动组合组、多 seed 或正式训练。两项主要比较未做多重比较校正；search 对 value 的比较为补充探索性统计。
