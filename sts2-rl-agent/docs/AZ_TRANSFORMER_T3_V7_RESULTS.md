# Transformer T3 V7 正式结果报告

日期：2026-10-17。范围：S 档、G2.3e 既有内容、V7 风险奖励，S 两轮 smoke 与独立 seed 42/43 各三轮正式训练。

## 1. 结论

- **T3 既有内容闭环完成**：两轮 smoke、双 seed 各三轮、联合冠军冻结、最终评估及训练工件审计完成。本次整理又独立复算两 seed 的底层工件、全部最终评估摘要和晋级门槛，结果一致。
- **冻结 network 效用增益门槛通过**：两个 seed 最终冠军相对各自独立初始化均有正增益。主指标为实际 V7 终局效用，非 value head 预测或胜率。
- **通用质量未验收**：最终测试是既有组成分布的新环境种子，不是未见组合/ID；两个 seed 不足以满足后续质量阶段至少三个 seed 的要求。
- **Boss 仍未解决**：最终测试每个 seed 的 Boss 子集 54 场，network/search 的初始和最终模型均全部死亡，平均效用 −1。训练曾到达后续阶段，不等于能赢完整 Boss 战。

## 2. 协议与实现

- S：6 层、宽 256、8 heads，5,671,522 参数；两个 seed 独立随机初始化，不继承 smoke/旧 MLP 权重。
- 正式每 seed 3 轮，每轮 180 场、16 更新、batch 64、microbatch 8、8 simulations；network 验证 256 场；CPU 2 workers，每 worker 1 thread。
- AdamW lr 0.0003、weight decay 0.0001，FP32、梯度裁剪 1.0；策略 CE + value MSE。
- reward `risk-terminal-v7`，search `dynamic-risk-puct-v2`，promotion `network-utility-v1`；配置 `configs/az_transformer_t3_v2`。
- V7 在搜索截断处使用根 HP 基准，在整场标签/验收使用开局 HP；获胜按最大 HP 归一化。公式及公开风险定义见 `AZ_TRANSFORMER_V7_DIAGNOSIS.md`。
- V7 同时修订奖励和搜索；本次不是同条件旧 MLP/Transformer 架构消融，不能将收益单独归因于架构。
