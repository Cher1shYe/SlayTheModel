# T4 / G2.3f Boss 可解性与自然后期轨迹审计

日期：2026-10-17。状态：**审计切片完成；T4 整体未完成；未启动新训练**。

## 结论

目前主要证据指向策略顺序和训练信号不足，而非持续空过或已确认的机制执行错误。冻结冠军在验证 Boss 上仍全部死亡，network 平均整场 V7 效用均为 **−1**，Boss 策略质量没有通过。胜率、阶段和伤害进度仅用于诊断；不替代 network 效用验收，也不修改死亡 −1 的用户指定奖励。

固定规则策略在现有训练配方中找到两场合法完整胜利，说明部分构筑确实可解。但 540 场只赢 2 场，不能把整套课程视为容易，也不能把其余配方称为无解。

- 对 594 场训练 Boss 的 21,933 步全部用原配方和动作 key 从第一形态重放，逐步比较公开状态及终局 outcome；不是只读取日志计数。

- 冻结 seed 42 的 candidate-1 和 seed 43 的 candidate-2，各重新推理 94 场验证 Boss，动作平局规则与原评估一致。188 场终局字段全部与原验证结果一致。

594 场全部死亡，无超时。第三形态共 147 场、2,309 个决策，约占 Boss 决策 10.53%；Burn 手持状态共 349 个决策。存在真实后期状态，但**没有成功完成后期的训练样本**。因此问题不是“后期完全未覆盖”，而是成功样本缺失、后期分布偏少且来自失败轨迹。

### 同配方可解性对照

发布的 `rule-win-9cdfa66bbf7f.json`：训练 seed 42、iteration 0、job 140，初始 HP 80。全部升级的构筑为 Shrug It Off×5、Body Slam×3，另有 Armaments、Equilibrium、Impervious、Iron Wave、Purity 各 1。固定规则策略从第一形态开始，13 回合 / 72 决策获胜，剩余 HP 24，效用 **0.93**。

在完全相同的配方和环境种子上重跑冻结 network：

- seed 42：74 决策，死于第三形态，最终伤害进度 0.553333，效用 −1。
- seed 43：30 决策，死于第一形态，进度 0.091667，效用 −1。第 0/1 步先打两张零格挡 Body Slam，再打 Armaments 和 Shrug，整场 **7 次零格挡 Body Slam**。这是可复现的顺序错误；不能用“构筑不可能获胜”解释该案例。
- 第一个动作已经分歧，但并不证明单改第一个动作即可获胜。seed 42 没有零格挡 Body Slam，仍有长期资源/阶段策略问题，尚未做逐动作因果归因。

另一个规则胜利来自训练 seed 43、iteration 2、job 129，初始 HP 40，同一牌组签名，最终 HP 2，效用 0.9025。没有据此调选新训练配方。

## 3. 构筑与课程

固定规则策略在每 seed 的 270 场 focused 配方中各赢 1 场：

| seed | 第二/第三形态 | 平均进度 | 平均效用 | 获胜 / 总场 |
|---|---:|---:|---:|---:|
| 42 | 270 / 249 | 0.670475 | −0.992852 | 1 / 270 |
| 43 | 270 / 256 | 0.672080 | −0.992954 | 1 / 270 |

规则策略明显更容易走到第三形态，但按整场效用仍很弱。构筑审计发现 focused 540 场只有 3 个牌组签名，重复 HP 档和环境种子不等于组合多样性；每 seed 含 retained 的全部 Boss 也仅 25 个牌组签名。

这些格挡构筑需要先积累格挡再使用 Body Slam，同时处理第一形态 Enrage 的技能触发力量、第二形态 Wound 污染、第三形态 Intangible 时序与 Burn。大量出牌本身不保证有效输出。当前证据不足以宣称全部构筑可解，或认定低 HP 配方必然无解；后续应逐配方保存可解性见证与失败范围。

## 4. 标签与搜索

- 21,933 个 Boss value 标签全部为 −1，符合 V7 的死亡语义，不是奖励写错。这个子集无法单靠终局 value 区分“第一形态早死”和“接近胜利后死亡”；更不应擅自把伤害进度重新混入死亡奖励。
- 训练策略标签累计 80,729 个正访问动作 / 92,144 个候选动作槽。8 simulations 的访问分布较粗；此计数只描述信息量，不证明搜索预算是唯一根因。
- 代码确认 `dynamic-risk-puct-v2` 在新叶/深度截断用 root-relative V7 cutoff utility 回传，**不使用网络 value 作为该叶的回传值**。所以改善 value 回归本身不会自动修好当前搜索的长期规划。
- Body Slam 的价值依赖前序格挡动作，而新叶截断可停在组合尚未完成时。短搜索可能无法充分区分组合顺序，这是与案例一致的待检验假设，尚未做不同预算/深度的因果对照。本轮未改搜索、奖励或 Replay 版本。
