# G2.3e：先验并列处理与父状态 FPU

日期：2026-10-16。用户授权每 seed 三轮快速验证，network-only 晋级，search 为观察指标。

## 冻结实现

保留默认 `legacy-zero-index-v1`，新增 `prior-tie-v1`、`parent-fpu-v1`、`parent-prior-v1`。先验并列处理仅在最终最大访问数并列且 temperature=0 时，按当前根先验、再按动作编号选择；temperature=1 仍从访问次数目标采样。PUCT 分数本身的同分次序不变。

FPU 指未访问动作的初始价值。父状态方案在节点展开时存下该公开状态的网络价值；选边时，未访问边使用这个固定值，已访问边继续使用真实回传的平均值。所有节点均适用，不引入隐藏信息、奖励塑形、价值清零或额外模拟。策略标签始终为原始访问次数归一化。

搜索版本进入配置、checkpoint、collect/evaluation job、评估缓存身份、新 Replay 兼容性及逐行元数据。旧默认行格式保留，新旧版本互相拒绝导入；恢复不能改变版本。相同模型可用于不同搜索方案的受控对照，但不复用不同方案的评估缓存或 Replay。旧源码及入口归档在 `output/az_g2_search_v1_prechange/source.zip`，旧模型／结果不修改。

## 三轮验证计划

内容、动作、编码及V6奖励不变。采样版本 `boss-search-course-v1` 保留每轮90原分布＋90聚焦Boss，原分布两轮覆盖180层。训练环境master为58/59，验证master188、最终测试master286；实际1552个环境种子唯一，与准备时135份历史运行清单及master48诊断配方无重叠。配置 `configs/az_g2_search_v1/`、清单 `data/az/g2_search_v1_manifest.json`。

复制G2.3c各seed冻结冠军的相同schema权重，优化器全新，不导入旧Replay。两轮smoke为4 simulations、每轮4更新；正式每seed三轮、每轮180场、16更新、batch64、8 simulations。network使用256场配对晋级；search仅观察。两个冠军共同冻结后运行新的216场最终测试，分原分布180与聚焦Boss36报告，并运行随机合法／受限规则基线。固定轮数结束，不因未晋级追加训练。

入口 `scripts/run_alphazero_continuous.py --boss-search --quick --iterations 3 --workers 4`。运行目录 `output/az_g2_search_v1_smoke_r2` 与 `output/az_g2_search_v1_quick`。结果按实际记录更新。

## Smoke 内存故障与采集修复

第一次8-worker smoke在首轮采集结果序列化 `_ForkingPickler.dumps` 时出现 `MemoryError`，尚未进入更新。失败目录 `output/az_g2_search_v1_smoke` 及日志 `docs/az_search_v1_smoke_run.txt` 保留，不计为通过。

旧采集器一次提交全轮任务，`list(pool.map(...))` 集中持有所有结果，协调器随后才逐场深拷贝提交Replay。有界实现增加 `iter_collect`：最多保留worker数量的任务，按原job顺序取结果并逐场提交，消费者提交后才派发下一任务；异常传播并取消尚未消费的任务。旧 `collect` 列表接口仍保留供调用方兼容。未改变对局seed、策略标签、Replay原子提交及固定轮数。

三个背压回归先失败后通过，包含窗口上限、顺序、重复job拒绝、异常不跳过；相关163项通过。新smoke与正式阶段使用4个worker降低并发内存。第一次全量6877项及30子测试通过、1跳过；采集修改后再次做全量验证。四组对照也在最终源码下重新固定运行到 `output/az_search_v1_probe_v3`，旧对照保留，不更改其源码摘要。

有界采集后的全量回归6884项及30子测试通过、1跳过。另测得历史Replay单决策Python堆约459KB；双seed同时常驻仍有峰值风险，因此新增显式释放非活跃seed内存副本、按原episode顺序校验后载入。磁盘样本、FIFO容量、采样概率、提交清单均不变；损坏文件恢复失败保持未载入。最终新增释放／恢复机制后170项相关回归通过（未将此前全量计数冒充最终源码全量）。最终源码四组对照为 `output/az_search_v1_probe_v4`，72场访问标签、公开轨迹及终局与v3除耗时外完全一致，复算通过。

正式运行前当前源码摘要为 `d77c12f17634f0be7cbdc89b2a1b8bdfaad7f052df7ab8018552edd5dc8a82cb`。新smoke目录为 `output/az_g2_search_v1_smoke_r2`，只有它成功后才用于正式运行的证据。

新 smoke 已通过：360 场、6739 决策、8 更新，两轮完整结束，未评估最终测试。正式三轮已使用该 smoke 的摘要启动，入口摘要 `5d705b4a17df977b5ac5bdc53bb97e4834e5c4740e92fe1ae3a6f59bf456e750`；完成情况以正式目录的 `progress.json` 和最终报告为准。

解释边界：正式训练只运行预先指定的合用版，不构成两项因素各自的训练消融。新旧批次使用不同环境种子，跨批阶段覆盖不能单独证明搜索修改的因果收益；因素对照仅来自上述固定配方的四组探针。验证集晋级不代替冻结后的最终增益检验。

## 三轮实际结果

正式双 seed 各三轮全部完成：1080 场、22353 决策、96 更新，含最终测试与基线约 30 分 42 秒。两个 seed 都仅首轮晋级，最终冠军均为各自 `candidate-0.pt`；后两轮未晋级，不追加训练。新 smoke、正式训练和最终测试无再次内存错误。

整体双 seed 学习增益 **未通过**。聚焦 Boss 的两个 seed、两模式均 0/36 胜，受限规则同样 0/36；随机合法基线总计 63/216 胜。聚焦 Boss 最终效用也下降，不能将原分布的局部改善称为 Boss 能力提升。search 退化仅如实记录，不改变 network-only 晋级规则。

Boss 训练共594场（其中聚焦540场），237场观察到第二阶段、3场第三阶段，Boss 胜利为零。Wound 入手1360次，Burn 入手仍为零；588次 Purity 提交均观察到正常退出。训练零超时。原始记录、训练量和统计的只读复算见 `az_search_v1_verification.json`，分组与覆盖见 `az_search_v1_mechanism_evidence.json`。

只读复算结果为 `artifact_and_statistics_checks_passed`：模型哈希及热启动权重、晋级链、全部Replay摘要／奖励、搜索版本、种子划分、最终统计均通过。7872条验证／测试记录及252条基线记录零超时、异常、非法动作；前者含配对和跨轮复用记录，不是7872个独立场景。机器可读验收见 `az_search_v1_acceptance.json`。

本批216场测试只有180个原分布层，许多层仅一个样本，分层bootstrap区间可能退化为点；“通过本批门槛”只描述冻结规则的结果，不能代表广泛组合的统计确定性。两 seed 共用同一测试配方，不是两份独立测试集。
