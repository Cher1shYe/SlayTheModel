## 本批交付

`sts2_env/az/card_state.py` 提供不可变 PublicCardState 和严格的 capture/restore。保存卡牌 token、当前／原始费用、临时费用标记、伤害／格挡、效果参数、单回合保留；token 包含升级信息。只有调用者显式提供的工厂和可变字段策略可以通过验证。额外战斗变量、未登记字段、附魔等未审计修改直接拒绝。

观察不保留 owner、真实实例 ID、世界对象或 RNG。原型核对会还原全局实例 ID 分配器；重建创建新卡，调用者须在既有粒子本地分配器上下文内调用。表示层允许临时费用／保留，不等于当前网络已经能接收这些状态。

`sts2_env/az/choice_state.py` 提供不可变 PublicChoiceState。保留候选的显示顺序、公开牌堆位置、每个候选的可变状态、已选索引、最少／最多选择数和跳过条件。相同 ID 的不同卡用公开位置区分。`bind_options` 只绑定到调用者提供的假想牌堆，拒绝缺失、状态不匹配和错误对象共享。

选择阶段动作 0 表示确认／跳过，动作 1+i 对应候选 i；严格验证动作合法性，绝不将确认解释成结束回合。114 个候选可完整映射现有 115 动作，115 个候选直接拒绝，不沿用引擎掩码中的静默截断。未来扩大容量必须发布新 action schema。

本批没有更改 expanded-v3 的内容白名单、InformationState、BeliefSampler 或网络输入，因此不会把只完成表示层的机制误放进训练。新模块是 G1 的基础接口，不是另一个搜索系统。

## 依赖审计与首批卡牌候选

源码参考为 `sts2_env/cards/base.py`、`sts2_env/core/selection.py`、`sts2_env/core/combat.py`、`sts2_env/cards/ironclad.py` 和 `sts2_env/gym_env/action_space.py`。当前审计依据本地引擎；本批不新增完整游戏规则一致性声明。

- True Grit：普通版随机消耗；升级版让玩家选择手牌消耗。依赖公开选择、独立选择 RNG、消耗守恒及暂停出牌恢复。
- Burning Pact：选择消耗后抽牌。除上述依赖，还必须保证抽牌在选择后执行且只执行一次，保持同一路径的未知牌序。
- Armaments：单选升级或升级全部手牌。依赖 token 变化、原始／临时费用交互、卡牌守恒账本。
- Anger：生成自身副本到弃牌。依赖生成来源、动态牌数和副本属性，不适用当前固定已知牌组守恒。
- Headbutt：选择弃牌放回抽牌堆顶。依赖公开顶牌记忆与真实未知顺序隔离。

这些是依赖审计候选，不是已经开放的训练内容。本批针对前两张牌测试真实引擎选择与续执行，但尚未实现其搜索粒子续执行。

## 后续批次与训练入口条件

G1.2（工程已完成，运行验收见新文档）：把公共卡牌状态接到新版信息与编码，增加公开的 choice/continuation 描述。根据机制 ID 在假想世界重新构建 resolver 与未完成出牌，禁止复制真实闭包、读取私有 pending 对象来替代公开信息。用 True Grit+、Burning Pact 贯通整局、隐藏扰动搜索不变性和串并行一致性。

G1.3：在已接通选择的基础上加入 Armaments、Anger、Headbutt，逐项完成变化／生成账本和已知牌序；随后分批处理保留、X 费、额外能力。具体训练内容须待机制验收后冻结。

每次正式内容发布均需新 information/encoder/content 版本、新目录与 Replay、生成划分、两轮 smoke，然后按最新要求每 seed 3 轮快速验证及最终报告。本批是基础接口批次，没有发布新内容或可训练模型，故尚未进行 G1 smoke／训练，不能用旧卡池训练代替新机制验收。

迁移预留：卡牌按语义 token 对齐，费用／效果按具名字段对齐，选择候选与普通手牌分开编码；未来迁移清单应记录旧字段到新字段的映射、新增参数初始化和价值头处理。本批不实施或声称权重迁移，旧 checkpoint 仍按旧 schema 加载。
