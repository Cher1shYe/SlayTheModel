# CombatSolver 0.38.1

## 简体中文

- 优化“必备工具”在回合开始选择弃牌时的路线计算，减少相同抽牌过程的重复计算，保留原有选牌候选和搜索范围。
- 优化“无色药水”和“宇宙药剂”生成卡牌时的路线计算，减少重复准备候选卡牌的开销。
- 减少伤害结算、卡牌标签查询和大型牌堆搜索中的临时内存分配；按实际需要计算部分攻击估值。
- 修复长时间搜索中，内存回收后即使资源已恢复，仍持续停留在回退模式的问题。
- 工坊中英文简介保留原有完整内容，移除外部链接；开源项目改为提供 GitHub 搜索名称。

感谢 ltlly 在 PR #90 中提供的优化与验证。性能收益因战斗与环境而异，本次没有统一的整体提速比例。

## English

- Optimized route calculation for Tools of the Trade's discard choices at the start of a turn, reducing repeated calculation of the same draw sequence while preserving existing choices and search scope.
- Optimized route calculation for cards generated by Colorless Potion and Cosmic Concoction, reducing repeated preparation of candidate cards.
- Reduced temporary allocations during damage resolution, card tag queries, and searches with large decks. Some attack evaluations are now calculated only when needed.
- Fixed long searches remaining in fallback mode after memory collection even when resources had recovered.
- Preserved the full English and Simplified Chinese Workshop descriptions while removing external links. Open-source projects are now identified by their GitHub search names.

Thanks to ltlly for the optimizations and validation in PR #90. Performance gains vary by encounter and environment; this release does not claim a single overall speedup percentage.
