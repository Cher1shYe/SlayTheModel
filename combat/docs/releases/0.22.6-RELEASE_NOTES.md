# Combat Solver v0.22.6 更新日志

本次创意工坊更新包含此前尚未上传的 `0.22.5` 与本次 `0.22.6` 改动。

## 敌方行动修复

- 修复双尾鼠呼叫支援、生成新的双尾鼠后，求解器可能在后续回合提示搜索动作回放失败的问题。
- 新生成的双尾鼠现在会在正确的回合边界决定首次行动，路线可以继续完成跨回合计算。

## 计算与回放稳定性

- 修复玩家在后台计算期间手动出牌后，既有搜索快照可能受到实机状态影响的问题，减少最终路线回放时出现多牌、少牌或找不到计划牌的情况。
- 改进同名卡牌的实例识别。牌组中的原牌与战斗中生成的复制牌现在能够正确区分，避免回放或路线标注选中错误卡牌。
- 修复部分出牌、选牌和力量变化尚未完全结算时，后续搜索可能初始化失败或计算失败的问题。
- 修复毒气炸弹自爆、怪物逃跑等行动结束后，求解器仍继续预测不存在的后续行动的问题。
- 修复目标身上已没有流沙坑时，狂乱逃离仍可能中止计算的问题。
- 提高战斗状态与监听顺序捕获的稳定性，减少偶发的搜索初始化失败。

本版本继续适配《杀戮尖塔 2》`0.111.0`，需要 RitsuLib `0.5.13` 或更高版本，仅支持单人战斗。
