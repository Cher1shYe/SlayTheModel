# Combat Solver v0.22.1 更新日志

## 路线稳定性

- 修复搜索过程中使用药水，或能力与遗物状态发生变化后，已经过期的路线仍可能被展示或执行，并在下一回合触发计划外重算的问题。
- 修复直飞产卵虫连续产卵时，新生成敌人的生命值预测可能与实机不一致，导致路线中断和重新计算的问题。
- 修复低语耳环在预测中可能于后续回合再次触发，造成手牌、能量、格挡和敌人生命偏离实机的问题。低语耳环现在只会在首回合按原版规则触发。
- 修复战斗状态中已经存在速度药水等临时敏捷效果时，求解器没有在回合结束正确回收敏捷，导致后续回合路线偏差的问题。

## 问题反馈

- 大幅精简在线上传和本地导出的问题包。现在只保留当前战斗；离开战斗后提交时，只保留最近结束的一场。
- 问题包不再包含截图、磁盘存档、此前楼层和更早战斗，同时缩减普通日志和检查点数量，降低上传体积与等待时间。
- 当前战斗的关键状态、牌堆、随机状态、路线、设置和附近日志仍会保留，不影响定位计划外重算、执行中止和计算失败。

本版本继续适配《杀戮尖塔 2》`0.111.0`，需要 RitsuLib `0.5.13` 或更高版本，仅支持单人战斗。
