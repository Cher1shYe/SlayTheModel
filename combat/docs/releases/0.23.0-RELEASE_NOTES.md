# Combat Solver v0.23.0 大版本更新日志

> 本说明汇总 `v0.22.0` 之后至 `v0.23.0` 的主要更新。

## 路线稳定性与计划外重算

- 修复使用药水、能力或遗物状态变化后，过期路线仍可能被展示或执行的问题；状态改变后会及时作废旧路线。
- 修复开局抽牌、洗牌和回合开始选牌连续发生时，选择错序、遗漏或跨回合状态不一致的问题。
- 修复回合开始选牌完成后，能量、格挡、覆甲、遗物计数或敌方状态可能重复结算并触发重算的问题。
- 修复低语耳环在后续回合重复触发，以及速度药水等临时敏捷没有在回合结束正确回收的问题。
- 修复力量变化、免费能力牌和遗物层数尚未完成结算时，路线标注、后续出牌或跨回合状态提前推进的问题。
- 修复玩家在后台计算期间手动出牌后，搜索快照可能受到实机状态影响，造成多牌、少牌或找不到计划牌的问题。
- 修复快速读档或离开旧战斗时，后台搜索继续读取已经卸载的战斗状态并导致计算失败的问题。

## 自动执行、同名卡牌与选牌

- 改进同名卡牌的实例识别。牌组原牌、战斗中生成的复制牌，以及带有不同升级、临时状态、附魔或苦难的同名牌都能正确区分。
- 修复原生选牌页面打开期间卡牌费用、伤害或关键词变化后，求解器可能找不到计划卡牌并中止执行的问题。
- 修复预知之滴面对多张同名、同升级卡牌时可能计算失败的问题。
- 修复惊逃与彼岸咆哮等回合末效果同时存在时触发顺序错误，导致头槌选牌与实机不一致的问题。
- 修复横祸自动打出虚空形态后，路线仍安排本回合后续动作的问题。由卡牌内层效果结束回合时，会正确进入下一回合并继续复用既有路线。
- 单回合执行进入烘焙手套等下一回合选牌页面时，会把选择交还玩家；路线面板同步显示当前回合。玩家明确点击“执行本回合”或启用“全自动”后，求解器再继续接管计划选择。

## 敌人、卡牌与战斗效果

- 修复直飞产卵虫连续产卵时，新生成敌人的生命值预测可能与实机不一致的问题。
- 修复双尾鼠呼叫支援后，新生成的双尾鼠首次行动决定时点错误，导致后续回合动作回放失败的问题。
- 修复敌方回合生成的怪物在首次行动前死亡时丢失初始行动记录，影响幻象复活和后续行动的问题。
- 修复击杀敌人后仍向死亡目标施加后续效果，错误触发抽牌或生成不可执行路线的问题。
- 修复毒气炸弹自爆、怪物逃跑等终止行动完成后，求解器仍继续预测后续行动的问题。
- 修复目标已没有流沙坑时，狂乱逃离仍可能中止计算的问题。
- 修复超质量体把并非由玩家创建的牌计入额外伤害的问题。
- 修复部分计算型伤害、格挡或抽牌卡牌进入选牌估值时可能直接导致搜索失败的问题。

## 路线策略

- 优化消亡粉末的路线判断，在破灭实际结算前识别确定的延迟伤害，减少强力药水路线被过早丢弃。
- 提高必备工具的长期策略价值，将其持续改变后续技能牌序的效果纳入路线判断。
- 根据玩家上传的重大手操优化问题重新校准路线，同时保留既有零战损与长线生存基线。

## 长线计算稳定性

- 修复长线搜索接近内存预算、完成局内回收后可能因回收状态读取错误而中断的问题。
- 内存检查点完成回收后会继续保留的搜索进度，减少高档预算和复杂战斗中的计算失败。
- 提高出牌、选牌、力量变化和监听顺序尚在结算时的状态捕获稳定性，减少偶发的搜索初始化失败。

## 问题反馈

- 大幅精简在线上传和本地导出的问题包，只保留当前战斗，或离开战斗后的最近一场。
- 问题包不再包含截图、磁盘存档、此前楼层和更早战斗；关键战斗状态、牌堆、随机状态、路线、设置与附近日志仍会保留。

本版本继续适配《杀戮尖塔 2》`0.111.0`，需要 RitsuLib `0.5.13` 或更高版本，仅支持单人战斗。搜索结果是当前时间、节点和内存预算内找到的最佳路线，不承诺数学意义上的全局最优解。
