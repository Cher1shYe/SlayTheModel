# Combat Solver v0.24.3 性能引导与药水策略界面

## 性能设置

- 本版本首次启动时会把所有玩家的性能预设统一调整为“中”，搜索内存预算统一为 `16 GB`。
- 性能预设和搜索内存预算现在分别保存；切换低、中、高或极高不再改动内存。
- 新安装默认使用“中”预设和 `16 GB`，搜索内存预算上限提高到 `256 GB`，玩家仍可自行调整。
- 推荐路线存在战损时，主界面顶部会提示前往“设置 > 性能”，改用高或极高后重试；点击提示可直接打开性能页。

## 搜索信息

- 搜索期间会实时显示已查阅的世界线数量。
- 搜索完成后会汇总显示总耗时和本场累计查阅的世界线数量；直接复用已有路线不会重复计数。

## 界面调整

- 药水策略面板移到主界面右侧，药水改为自适应多列卡片：上方显示图标，下方显示名称、槽位和紧凑策略选项。
- 药水策略、设置、收起、重新计算、全自动和状态详情统一使用与“执行本回合”相同的字体和按钮风格。
- 全自动状态统一显示为“开”或“关”。

本版本继续适配《杀戮尖塔 2》`0.111.0`，需要 RitsuLib `0.5.13` 或更高版本。
