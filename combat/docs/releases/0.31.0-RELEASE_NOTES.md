# Combat Solver v0.31.0

本次更新以合并玩家 PR 贡献为主，共收录 9 项优化与修复。感谢 s1f102500012、bingyang1132、ltlly、mykmlinzhuo 的贡献，也感谢提供问题反馈与复现场景的玩家。

- PR #39（s1f102500012）：降低复杂战斗求解时的内存开销，减少反复搜索产生的临时内存占用。
- PR #40（bingyang1132）：路线中的治疗收益纳入战损评价；每回合生命显示改为净变化，并用绿色区分回血，让回血路线的价值更清楚。
- PR #41（bingyang1132）：战后遗物回血加入路线显示，无条件战后回血也参与路线比较；条件触发的战后回血目前只显示。
- PR #42（s1f102500012）：仅修改地图、事件等战斗外内容的部分 Mod，不再被误判为与求解器不兼容。
- PR #44（ltlly）：进一步减少大牌组搜索的内存开销，改善连续搜索时的内存整理。
- PR #45（ltlly）：改善长循环和复杂选牌路线的搜索恢复，修复自动出牌、回手顺序及战斗结束回合判断中的问题。
- PR #46（bingyang1132）：调整消耗、转变的选牌优先级，减少把有限移除机会用于回合末会自行消耗的手牌；优化原版起手打击、防御的移除权重。
- PR #47（bingyang1132）：将一次性保命遗物的消耗纳入路线代价，减少为了回血而主动触发复活的倾向；必须依靠复活才能获胜时仍会使用。
- PR #48（mykmlinzhuo）：修复奥斯提死亡后连续使用碎骨仍多算格挡、导致路线防御被高估的问题。

搜索与计价调整可能改变部分战斗的路线、战损和结束回合，不保证每场都优于旧版本。

适配《杀戮尖塔 2》0.111.0，需要 RitsuLib 0.5.13 或更高版本，仅支持单人战斗。
