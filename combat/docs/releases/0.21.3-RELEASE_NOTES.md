# Combat Solver v0.21.3 更新日志

本次更新集中修复部分跨回合计划外重算与路线执行偏差：

- 修复战斗中变换出的卡牌没有正确继承入场状态的问题。熵变换出的女妖之嚎等卡牌现在会按本场已经打出的虚无牌正确计算费用。
- 修复迭代跨回合错误累计状态牌抽取次数的问题。每个新回合都会重新识别本回合抽到的第一张状态牌。
- 修复野性把上一回合零费攻击计入当前回合的问题，后续出牌与牌堆去向现在和实机一致。
- 修复暗黑充能球连续激发时的死亡结算顺序。前一次激发造成的死亡、复活、召唤、力量与格挡变化会先完成，再结算下一次激发。
- 加强跨回合路线核对，减少手牌相同但隐藏的本回合历史不同所引起的计划外重算。
