# Combat Solver v0.21.0 更新日志

## 多核搜索

- 本版合并了 [ltlly](https://github.com/ltlly) 提交的 PR #8，为求解器加入多核并行搜索。感谢他完成这项重要贡献。
- 求解器现在可以并行展开候选路线。在适合并行的复杂、高分支战斗中，预计可缩短约 `30%–50%` 的计算时间，部分场景可能获得更高提升；实际效果取决于处理器、搜索并行度和战斗复杂度。
- 设置中新增“搜索并行度”，可在 `1–8` 之间调整，默认值为 `2`。提高并行度会增加 CPU 和内存占用，默认值适合大多数玩家。
- 并行搜索保持原有的路线选择顺序和节点预算语义；单线程与双线程的固定场景结果一致。
- 达到节点预算后会及时释放未采用的搜索快照，降低长线计算结束后的内存占用。

## 战斗修复

- 修复刮削抽到贪婪等负费用牌时的处理。求解器不再把不可打出的牌当作 `0` 费牌留在手中，后续内存清理等选牌路线与实机保持一致。
- 修复吹哨造成眩晕后的怪物行动续接。史莱姆狂战士会在眩晕结束后恢复被打断的行动，佩尔之眼额外回合后的路线也能正确续用。
- 保持暴政等下一回合选牌的控制边界：执行本回合后停在下一回合原生选牌页面，求解器不会提前替玩家完成选择。
- 修复部分长线计算在完成选牌并获得力量后可能出现的搜索动作回放失败。
