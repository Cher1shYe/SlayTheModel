# Combat Solver v0.22.0 大版本更新日志

> 本说明汇总 `v0.21.1` 至 `v0.22.0` 的主要更新。

## 多核搜索与性能

- 求解器现已支持多核并行搜索。在适合并行的复杂、高分支战斗中，预计可缩短约 `30%–50%` 的计算时间，部分场景可能获得更高提升；实际效果取决于处理器、搜索并行度和战斗复杂度。
- 搜索并行度可选择“关闭（单线程）”或 `2–8`。至少有 4 个可用逻辑处理器时，新安装默认使用 `4`；2–3 个时默认使用 `2`；只有 1 个时使用单线程。玩家手动选择始终优先。
- 进一步优化大型牌组、复杂选牌、牌堆定位、随机状态分叉和生成牌药水的搜索开销，明显减少长线搜索中的内存分配与峰值压力。这些优化不缩小搜索预算，也不改变评分、路线接受顺序或药水策略。
- 搜索内存预算现在会准确采用低、中、高、极高档对应的 `6 / 8 / 12 / 16 GB`；自定义 `1–16 GB` 按保存值生效，不再存在隐藏上限。更改预算后，下一次搜索会按新值重新建立内存区域。
- 修复节点预算结束后部分已淘汰搜索状态没有及时释放的问题，降低长线搜索和连续战斗的额外内存占用。

## 并行稳定性

- 修复启用 BaseLib 时，多核搜索处理带附加状态或附魔的卡牌可能出现“同一个键已被添加”并导致计算失败的问题。
- 修复部分能力、怪物状态和本地化文本首次参与多核搜索时，可能出现集合被修改、空引用、搜索初始化失败或计算失败的问题。
- 修复梦魇、缩小等效果在后台搜索中生成显示文本时引发的并发异常。
- 并行搜索发生异常时，提示会引导玩家先上传问题包，再切换为“关闭（单线程）”重试。

## 跨回合与选牌修复

- 完整记录九条战斗 RNG 的内部状态，不再把“调用次数相同、实际随机状态不同”的分支错误合并，减少后续牌序偏差与计划外重算。
- 修复赌博筹码等开局选牌完成后，备用路线仍要求已经换走的牌留在手中，导致自动执行失败的问题。
- 修复同一张探寻打击在后续回合再次打出时沿用上一次选牌状态的问题。
- 修复战斗中变换出的卡牌没有正确执行入场流程的问题；其费用、监听效果和跨回合状态现在按实机结果推进。
- 修复迭代把上一回合的状态牌抽取记录带到新回合，以及野性把上一回合零费攻击计入当前回合的问题。
- 修复暗黑充能球连续激发时的死亡结算顺序。前一次激发造成的死亡、复活、召唤、力量和格挡变化会先完成，再结算下一次激发。
- 修复花样百出自动打出微光时，抽牌洗牌触发战略选牌后两层选择顺序错误的问题。
- 修复新召唤的幻象怪物在首次行动前死亡时无法正确进入复活路线的问题。
- 修复佩尔军团在部分出牌流程中遗留状态，导致后续路线计算失败的问题。

## 设置与界面

- 设置页重组为“常规 / 性能 / 反馈”三页。求解器、药水、通知、自动执行、搜索预算和问题反馈各归其位，复杂搜索参数默认折叠。
- 性能预设会直接显示对应的快搜、深搜和内存预算数值；关闭设置页再进入时不再被误判为“自定义”，只有实际修改数值后才会切换为自定义配置。
- 新增 Windows 搜索结束通知。搜索成功、失败、停止或结果失效时均可发送系统通知和提示音；默认只在游戏不处于前台时通知，也可以改为“始终通知”或关闭。非 Windows 平台不会调用 Windows 通知接口。
- 默认继续使用深色界面，并新增可选浅色主题。主题切换后会保留当前路线、设置页面、折叠状态和执行进度。
- 新增 `25%–100%` 覆盖层透明度调节，修改后立即生效。滑块使用清晰可见的轨道、强调色进度段和独立拖动圆点。
- 优化设置项名称和操作方向：“禁用求解器”改为“启用求解器”，“No-GC 预算”改为“搜索内存预算”，药水和通知选项也进行了合并整理。

## 问题反馈

- 优化战斗检查点和问题包记录流程，减少连续自动执行期间整理、序列化和写盘造成的画面卡顿。
- 同一时刻的重复检查点会复用已有记录；导出或上传问题包时会等待后台记录完整结束，不会生成缺少关键检查点的包。
- 在线提交的自动分类新增 Combat Solver 版本号，即使本场没有检测到明确异常，也可以在解压问题包前按版本筛选反馈。
- 问题包上传、导出、详细诊断和联系方式集中到“反馈”页，上传进度紧跟操作按钮显示。
