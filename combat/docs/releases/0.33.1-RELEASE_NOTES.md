# Combat Solver 0.33.1：在线统计

本版本未单独上传创意工坊，内容并入 0.33.2 发布。

- 新增在线状态统计，默认开启，可在设置的“在线统计”区域随时关闭，选择自动保存。
- 开启后定期向作者发送随机安装标识、昵称、角色、楼层、当前战斗、预计战损和 Mod 版本，不上传完整路线；尚未算出完整战损时显示“未知”。
- 作者后台可查看当前在线列表、战斗状态和历史人数折线。离线后清除玩家详情，历史只保留人数。
- 无头求解子进程不重复计入在线，多人跑局不发送；连接失败不影响正常求解。

详细字段与统计口径见 [在线统计说明](../ONLINE_STATISTICS.md)。
