# Combat Solver 0.31.3

本次更新合并社区 PR，开放 API，为更多角色和伴生 Mod 的适配提供基础。感谢社区作者的贡献。

- **开放战前预测 API**：地图信息类 Mod 可在进入战斗前查询预计战损、用药和战斗结果，也可评估假设战斗。支持后台预测复用、停止和静音，目前限 Windows 单人模式，需要伴生 Mod 调用。
- **合并角色适配 PR #50–#55**：补充第三方持续效果估值、药水选择和牌堆弃牌支持，完善未适配出牌条件的提示，并提供适配手册。具体角色效果由对应适配 Mod 提供。
- **合并优化 PR #49**：优化部分环境下药水相关搜索的开销。
- **更新开发文档**：README 明确已发布 API 和角色适配入口的最低版本要求。
- **依赖更新**：需要 RitsuLib `0.5.18` 或更高版本，游戏版本为 `0.111.0`。
