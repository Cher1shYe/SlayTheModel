# Combat Solver v0.22.7 更新日志

## 回合开始选牌修复

- 修复执行本回合后进入下一回合时，求解器可能在烘焙手套等回合开始选牌页面中提前替玩家完成选择的问题。单回合执行现在会停在原生选牌页面，等待玩家决定是否继续接管。
- 修复游戏已经进入下一回合选牌阶段，但路线面板仍停留在上一回合的问题。面板现在会及时切换到当前回合，并展示这一回合及后续计划。
- 在选牌页面明确点击“执行本回合”或启用“全自动”后，求解器会继续完成计划选择并沿用既有跨回合路线。

本版本继续适配《杀戮尖塔 2》`0.111.0`，需要 RitsuLib `0.5.13` 或更高版本，仅支持单人战斗。
