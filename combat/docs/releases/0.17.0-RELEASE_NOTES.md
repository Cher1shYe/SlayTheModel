# Combat Solver v0.17.0 更新日志

本次更新重点改善求解器对整场战损、永久资源和成长路线的判断，让推荐路线不只考虑眼前伤害，也会更认真地保护整局收益。

## 路线质量优化

- 力量药、敏捷药等整场持续生效的药水，如果最终路线决定使用，会安排在首张牌之前使用，避免拖到后续回合才获得增益。
- 整场战损现在会跨治疗和复活持续累计。触发蜥蜴尾巴后，路线仍会保留复活前受到的伤害，并在对应回合标注“蜥蜴尾巴：复活”。
- 最大生命现在与当前生命同等重要。求解器会避免在并非必要时打出至亮之焰；只有确实能改善生存或胜负结果时才会承担最大生命代价。
- 改善精简牌组和小循环路线的判断。已经形成更优循环时，求解器会避免无意义地使用愤怒继续扩充牌组；愤怒是必要击杀手段时仍会正常使用。
- 训练假人事件以击杀目标为成功条件，不再把倒计时结束但未击杀的路线当作胜利。

## 成长与资源策略

- 支持灵魂异鱼加入的呼唤，求解器现在能够计算其伤害与回合末代价，并在合适路线中主动打出。
- 提高遗传算法、巨镰和黏糊防御等战斗内成长牌的培养价值，不再只按它们当前的即时数值判断。
- 求解器会更积极地争取狂宴、狩猎和贪婪之手的斩杀收益。
- 时候未到的治疗，以及王国资产、禁忌魔典和炼制药水带来的长期资源，现在会参与路线比较。
- 牌的重放与灵魂之力附魔产生的额外成长会按实际结算次数累计，临时复制不会被误算成永久成长。
