# Combat Solver v0.25.1 搜索稳定性修复

## 计算与重算

- 修复部分长选牌连锁会过早耗尽搜索时间、只能搜索少量后续回合的问题；大型 Boss 战会更合理地把时间留给后续回合。
- 修复洗牌生成卡牌、同回合多次随机选牌等情况下，推荐路线与实际选牌状态不一致并导致计算失败或计划外重算的问题。
- 修复搜索达到时间上限时可能返回尚未结束当前回合的路线，随后提示计划耗尽并重新计算的问题。

## 药水与卡牌

- 修复自动触发或自动生成的药水被误算为玩家主动用药，导致全部药水均为“智能使用”时仍提示药水策略无法满足的问题。
- 修复木乃伊手在同回合连续打出能力牌时，临时费用与随机选牌结果可能和游戏实际状态不一致的问题。
- 修复部分旧问题包中的选牌回放失败；单条选牌分支不可执行时会继续比较其他合法路线。

## 界面

- “手动 GC”从战斗主界面移到“设置 > 性能 > 内存维护”，减少主界面底栏拥挤。

本版本继续适配《杀戮尖塔 2》`0.111.0`，需要 RitsuLib `0.5.13` 或更高版本。
