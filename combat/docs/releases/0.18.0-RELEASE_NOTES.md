# Combat Solver v0.18.0 更新日志

本次更新集中修复复杂战斗中的路线失配、计划外重算和用药判断，并继续改善路线质量。

## 稳定性

- 修复如此甚好、既定事项、知识恶魔及连续选牌在跨回合执行时的牌堆、抽牌和选择顺序偏差。
- 修复历史课、惊逃与佩尔之眼同时生效时的回合记录错误，额外回合与自动出牌现在会按原版规则执行。
- 修复鬼祟珊瑚群、情感芯片、回响形态和刀扇生成的小刀与实机结算不一致的问题。
- 修复多个遭遇中的初始化失败、搜索动作回放失败、自动执行中断和计划外重算，包括精神过载与复杂自动出牌路线。
- 修复抉择，抉择等连续多层选牌容易长时间无结果的问题，并减少长线计算中的反复卡顿。

## 药水

- 智能用药现在分别判断每瓶药水的实际收益，不再让收益不足的药水借用其他药水的效果通过门槛。
- 改进格挡药水、痊愈药水、再生药水、易伤药水等药水的使用与保留判断。
- “至少使用一瓶”在长线搜索尚未到达终局时，也能返回当前最优的可执行用药路线。
- 求解器会继续严格遵守“禁用药水”等玩家设置。

## 路线质量

- 改进孙子兵法相关路线的防守与铺垫保留，求解器会更合理地利用灵动步法等跨回合收益。
- 改善女王战中的前期铺垫选择，更重视余像与计划妥当等长期收益。
