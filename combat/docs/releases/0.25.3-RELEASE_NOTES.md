# Combat Solver v0.25.3 计划外重算修复

## 战斗状态同步

- 修复斧兵复生、千足虫重组等召唤效果可能让新生怪物提前行动，导致后续回合计划外重算的问题。
- 修复异蛙寄生虫被闪电球击杀时，后续玻璃球没有命中新生成扭动虫的问题。
- 修复部分增加充能球槽位的卡牌、遗物和药水可能预测超过原版 10 槽上限的问题。

## 卡牌、能力与遗物

- 修复乱战与爆破同时出现时，爆破可能被重复计算的问题。
- 修复六边形效果动态赋予虚无后，纸钱计数与实际牌堆不同步的问题。
- 修复佩尔士兵遗漏部分卡牌格挡、躁动之灯错误翻倍后续卡牌效果的问题。
- 修复倾泻等自动出牌效果没有继承本回合完整格挡历史，导致坚不可摧重复翻倍的问题。

本版本继续适配《杀戮尖塔 2》`0.111.0`，需要 RitsuLib `0.5.13` 或更高版本。
