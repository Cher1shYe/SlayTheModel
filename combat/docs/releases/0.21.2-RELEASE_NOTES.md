# Combat Solver v0.21.2 更新日志

## 搜索并行度

- 默认并行度现在会根据电脑可用的逻辑处理器数量自动选择：4 个及以上默认使用 `4`，2–3 个默认使用 `2`，只有 1 个时自动使用单线程。
- 玩家手动选择的并行度始终优先，不会被自动配置覆盖。
- 仍可在设置中随时选择“关闭（单线程）”，用于降低 CPU 和内存压力，或在遇到并行搜索异常时临时规避。

## 设置修复

- 修复选择低、中、高、极高档位后，关闭设置页再进入会被误判为“自定义”的问题。
- 现在只有实际修改搜索时间、Beam 宽度、节点、分支或 No-GC 预算时，档位才会切换为“自定义”。
