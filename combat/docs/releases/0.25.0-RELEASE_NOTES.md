# Combat Solver v0.25.0 搜索性能与等待体验优化

## 搜索性能

- 智能用药搜索改为“无药 → 恰好一瓶 → 恰好两瓶……”逐层推进；同一药量下的所有药水会在一次搜索中共同比较，不再逐瓶重复计算。
- 无药路线存活时，每预计损失 `9 HP` 才开放一瓶普通药的搜索额度；找到达到省血门槛的路线后立即停止，不再继续搜索不必要的多药组合。
- 无药路线会死亡时，搜索会逐层推进到第一条生还路线，优先把计算时间用于真正影响胜负的用药方案。
- 优化搜索内存管理，减少搜索结束时集中回收带来的等待；主界面保留“手动 GC”按钮，玩家可按需主动释放内存。

## 等待与操作体验

- 搜索耗时、已查阅世界线数量和进度在各层连续累计，不再表现为反复从头计算。
- 搜索期间只显示已经打赢整场的完整路线及其预计用药数和战损，不会把尚未打完的阶段结果误报为整场战损；后续只会替换为严格更优的结果。
- 找到可执行路线后，可以直接采用当前路线，不必等待更深层搜索结束。
- 搜索阶段会明确显示当前正在计算无药路线或恰好几瓶药的路线。
- 搜索状态改为双行显示搜索阶段、当前路线和世界线数量，不再被面板边缘截断。
- 出现战损时会提示提高性能预设重试；点击消息可永久关闭提示，不再自动跳转设置页。

## 药水策略与界面

- 强制使用和禁用保护会按药水槽位与药水身份持久保存；同一瓶药进入下一场战斗后仍保留玩家选择。
- 药水被使用或槽位换成新药后，旧策略不会套到新药上；新获得的药水默认智能使用。
- 药水策略改为主面板右侧的单列窄侧栏；药水策略、设置和收起按钮保持在主面板原位。

本版本继续适配《杀戮尖塔 2》`0.111.0`，需要 RitsuLib `0.5.13` 或更高版本。
