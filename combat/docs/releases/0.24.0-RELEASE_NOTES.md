# Combat Solver v0.24.0 长线策略重大更新

`0.24.0` 是一次面向路线质量的大版本更新。求解器现在会更系统地保留需要能力铺垫、跨回合资源、卡牌联动、主动卖血和关键药水才能兑现的路线，而不是只偏向眼前一回合的直接伤害或格挡。

## 长线策略重大优化

- 重新量化持续能力的长期收益。伤害、防伤、抽牌、能量、减费、生成牌、成长和多次触发会按当前战斗中实际可兑现的次数参与路线判断。
- 新增独立的长期资源搜索通道，让保留牌、牌堆整理、跨回合能量、奥斯蒂资源和延迟收益不会被即时战损路线过早挤掉。
- 加强卡牌联动与启动顺序判断，能够为先过牌再减费、资源牌连接防御、能力牌连接多次出牌等组合保留完整路线。
- 改进主动卖血判断。只有确实换来击杀进度、资源、控制、牌访问或后续生存空间的路线才会被保留，最终仍按整场真实战损选择。
- 改进 Boss 阶段转换、致命奖励牌、生成牌药水和跨回合选择的判断，减少只看当前阶段或即时分数造成的误判。

## 逐瓶药水策略

- 主界面右侧新增“药水策略”折叠按钮，实时读取当前药水栏并显示药水图标和名称。
- 每瓶药水可以独立选择“智能使用”“强制使用”或“禁用 / 保护”。新获得的药水默认使用智能策略。
- 强制使用会要求最终路线实际交出指定药水；禁用会保护该瓶药，不让它进入主动用药候选。
- 智能用药会主动补查原路线遗漏的药水窗口，并继续按每瓶 `9 HP` 的机会成本判断是否值得使用。石化蟾蜍每场生成的石头药按可再生资源处理。
- 加强多瓶药、生成牌药水、资源牌接药水、药水接能力牌和阶段转换前用药的联合路线。
- 原设置页中的整场药水策略已移除，逐瓶选择成为唯一的玩家药水策略入口。

## 更高的默认路线质量

- 新安装和恢复默认现在直接使用“极高”性能档，为复杂战斗提供更充分的搜索时间、节点和内存预算。
- 已经明确选择其他预设或自定义参数的玩家不会被覆盖。
- 继续默认使用多核并行搜索；大牌组、复杂随机选择和长时间连续战斗中的内存占用与回收停顿进一步降低。

## 稳定性与兼容性

- 修复赌博筹码、烘焙手套、工具箱和选择悖论等回合开始选项的重算问题：选牌页仍打开时会立即刷新推荐，玩家已经跳过或手动干预后则等待选项结算，再按实际局面重新规划，不再提示“当前不是玩家出牌阶段”。
- 将较重的战斗结束清理错开到击杀和结束动画后的空闲时段，减少击杀瞬间的卡顿。
- 改进大型附魔牌组、第三方卡牌修改器、复杂选择和跨战斗连续搜索的稳定性。
- 修复部分旧回放在明确没有第三方卡牌修改状态时无法恢复的问题。
- 多人模式下求解器现在保持完全停用，不会创建搜索窗口或介入其他玩家回合。
- Android 和 iOS 会避开平台不支持的运行时内存接口，使用兼容的低延迟模式。

本版本继续适配《杀戮尖塔 2》`0.111.0`，需要 RitsuLib `0.5.13` 或更高版本。Combat Solver 只支持单人战斗；搜索结果是当前时间、节点和内存预算内找到的最佳路线，不承诺数学意义上的全局最优解。
