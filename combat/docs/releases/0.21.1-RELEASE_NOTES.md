# Combat Solver v0.21.1 更新日志

> 本版取代已经撤下的 `v0.21.0`，包含多核搜索及其稳定性修复。

## 多核搜索

- 合并了 [ltlly](https://github.com/ltlly) 提交的 PR #8，为求解器加入多核并行搜索。感谢他完成这项重要贡献。
- 在适合并行的复杂、高分支战斗中，预计可缩短约 `30%–50%` 的计算时间，部分场景可能获得更高提升；实际效果取决于处理器、搜索并行度和战斗复杂度。
- “搜索并行度”改为选择框，可选择“关闭（单线程）”或 `2–8`，默认值为 `2`。提高并行度会增加 CPU 和内存占用。

## 并行稳定性修复

- 修复启用 BaseLib 时，多核搜索克隆带附加状态的卡牌可能出现 `An item with the same key has already been added` 并导致计算失败的问题。
- 修复多核搜索处理部分能力与怪物状态时可能出现集合被修改、空引用或搜索初始化失败的问题。受感染棱镜、缩小甲虫、蔓生爬虫等相关战斗现在使用同一套稳定处理。
- 修复覆盖搜索、首回合准备选牌和长线计算中的共同并行路径，不再依赖具体角色、卡牌或怪物的单独适配。
- 并行搜索发生异常时会继续提示上传问题包，并建议临时切换为“关闭（单线程）”后重试。

## 战斗修复

- 修复刮削抽到贪婪等负费用牌时的处理，后续内存清理等选牌路线与实机保持一致。
- 修复吹哨造成眩晕后的怪物行动续接；史莱姆狂战士会恢复被打断的行动，佩尔之眼额外回合后的路线也能正确续用。
- 保持暴政等下一回合选牌的控制边界：执行本回合后停在下一回合原生选牌页面，求解器不会提前替玩家完成选择。
- 修复部分长线计算在完成选牌并获得力量后可能出现的搜索动作回放失败。
