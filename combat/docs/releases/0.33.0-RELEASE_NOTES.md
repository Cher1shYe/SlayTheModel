# Combat Solver 0.33.0：战斗预测集中修复与适配扩展

- 集中修复战斗预测与路线复用：包括包围朝向、能力触发顺序、重复死亡结算、重复出牌计数，以及召唤敌人的后续行动预测。
- 修复部分回合末抽牌、弃牌重抽和开局生成牌的顺序差异，减少由手牌、牌堆和随机结果偏差引起的意外重算。
- 修复部分增能效果与战斗结束后的预测，避免推荐已经无法执行的后续动作。
- 修复开局选牌时重算与自动接管同时发生会执行旧计划的问题，并修复部分搜索中断。
- 合入污染层数修复，保留战斗开始时实际叠加的层数，减少因此发生的逐回合重算。
- 增加第三方能力隐藏状态的适配入口，为更多角色适配提供基础；具体角色效果仍由对应适配 Mod 提供。
- 明确提示与 WheelchairSpire 不兼容。

本版发布当前已完成的一批修复，其余报告继续保留跟进。需要游戏 0.111.0、RitsuLib 0.5.18 或更高版本，仅支持单人模式。
