# CombatSolver 0.34.5

- 修复持有幻影之刃、致死性或不动时，后续出牌可能改变预测中的能力顺序，导致计划外重算或自动执行暂停的问题。
- 修复狂战士在回合开始抽牌并自动出牌后，计划漏记这次出牌，从而在下一回合触发计划外重算的问题。

- Fixed unexpected replans and auto-play pauses caused by Phantom Blades, Lethality, or Unmovable changing position in the predicted Power order after later card plays.
- Fixed Hellraiser's turn-start automatic Strike being omitted from the new turn's play history, which could trigger an unexpected replan on the following turn.
