# Combat Solver v0.22.2 更新日志

## 路线与重算修复

- 修复开局抽牌、洗牌和回合开始选牌连续发生时，部分选择可能错序、遗漏或造成计划外重算的问题。
- 修复卡牌在原生选牌页面打开期间发生费用、伤害或关键词变化后，求解器可能找不到计划卡牌并中止执行的问题。
- 修复力量变化、免费能力牌等遗物层数没有及时结算，导致最终路线标注、后续出牌或跨回合状态与实机不一致的问题。
- 修复击杀敌人后，求解器仍对已经死亡的目标施加后续效果，进而错误触发抽牌或生成不可执行路线的问题。

## 敌人与卡牌效果

- 修复敌方回合生成的怪物在首次行动前死亡时，初始行动记录丢失，导致幻象复活或后续行动计算失败的问题。
- 修复超质量体把并非由玩家创建的牌计入额外伤害，造成伤害预测偏高的问题。
- 修复快速读档或离开旧战斗时，后台搜索仍读取已经卸载的怪物行动状态，导致计算失败的问题。

本版本继续适配《杀戮尖塔 2》`0.111.0`，需要 RitsuLib `0.5.13` 或更高版本，仅支持单人战斗。
