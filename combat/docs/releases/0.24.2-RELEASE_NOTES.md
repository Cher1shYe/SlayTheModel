# Combat Solver v0.24.2 智能药水修复

## 修复内容

- 修复赌徒特酿在后续回合使用时，智能药水补查可能错误地把该动作当作首回合动作并导致整次计算失败的问题。
- 修复所有药水均设为“智能使用”时，部分可选药水路线搜索失败却提示“本场药水策略要求至少使用一瓶”的问题。
- 智能药水的某条补查路线不可用时，求解器会继续比较已有合法路线；玩家明确设置“强制使用”的药水仍会严格执行要求。
- 固定路线动作异常现在会在日志中记录动作类型、回合与卡牌或药水身份，方便问题包直接定位首个错误。

本版本继续适配《杀戮尖塔 2》`0.111.0`，需要 RitsuLib `0.5.13` 或更高版本。
