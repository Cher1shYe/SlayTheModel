# Combat Solver v0.20.0 更新日志

## 重大更新：游戏内在线上传问题包

- 设置页面新增“上传问题包”。遇到计算失败、自动执行中止、计划外重算或找到更优世界线时，可以直接填写问题描述并上传，无需再手动导出后另行发送。
- 上传内容会在玩家描述后附上本场检测到的错误分类，帮助开发者在解压日志前先区分更优世界线、计划外重算、战损上升、选牌异常和搜索失败等问题。
- 新增“反馈联系QQ”设置，只需填写一次，后续上传会自动带上，方便开发者联系反馈玩家。
- 上传过程会显示已发送量、总大小和服务器确认状态。传输中及等待确认时均可取消；上传失败或取消后会保留本地问题包，成功后会显示反馈编号。
- 本功能的接收服务器和后端由社区朋友 [iRyougi](https://github.com/iRyougi) 提供支持，在此特别感谢。

## 选牌与自动执行

- 修复烘焙手套首回合边界。原生选牌页面出现后，求解器会先计算并展示预计选择，等待玩家点击执行或开启全自动后才确认，不会在路线刚算好时自行替玩家选牌或出牌。
- 修复武装只有一个未升级目标时，原版自动完成升级后求解器无法核对目标、导致自动执行中止的问题。
- 修复知识恶魔的诅咒选择被结束回合战损复核错误拦截的问题。包括打出愤怒后的结束回合在内，现可正常进入原生诅咒选择并继续全自动。

## 战斗稳定性

- 修复毒气炸弹和瀑布巨兽自毁后，相关死亡联动没有继续结算的问题。
- 修复额外回合中情感芯片读取上一回合受伤记录不正确的问题。
