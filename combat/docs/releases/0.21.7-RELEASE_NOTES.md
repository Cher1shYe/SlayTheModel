# Combat Solver v0.21.7 更新日志

- 新增 Windows 搜索结束通知。搜索成功、失败、停止或结果失效时会通过系统通知和提示音告知玩家；默认只在游戏不处于前台时通知，也可在设置中改为始终通知或关闭。
- 设置页重组为“常规 / 性能 / 反馈”三页，求解器开关、自动执行、搜索预算和问题反馈各归其位，常用选项更容易找到。
- 性能预设现在直接显示对应的快搜、深搜和内存预算数值；自定义搜索参数默认折叠，只有实际修改数值后才会切换为“自定义”。
- 优化设置项名称和操作方向：“禁用求解器”改为“启用求解器”，“No-GC 预算”改为“搜索内存预算”，药水与通知选项也进行了合并整理。
- 问题包上传、导出、详细诊断和联系方式集中到反馈页，上传进度紧跟操作按钮显示。
