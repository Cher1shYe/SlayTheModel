# Combat Solver 0.32.0

## 局外成长策略

- 主界面新增“成长策略”侧栏，可分别配置贪婪之手、狩猎、狂宴、王国资产、炼制药水、遗传算法、巨镰和黏糊防御，每次成功获得收益愿意承担多少额外战损。
- 默认全部为 0：同等战损时仍优先获取局外收益，再比较结束战斗的回合。多次成功触发逐次累计，只有实际取得收益才计入额度。
- 始终优先考虑生存与完整胜利；路线面板继续显示真实预计战损。搜索仍受所选时间和节点预算限制。

## 设置与操作

- 成长额度自动保存，点击数字输入框外部即可应用，回车同样可用；设置页输入框也支持点击外部保存。
- 原“可接受战损”改名为“提前结束搜索的战损阈值”，位于常规设置的求解器区域。有成长目标或非零成长额度时不生效，避免提前结束收益比较。

## 适配支持

- 补充第三方卡牌的自定义选项支持，为更多角色适配提供基础，具体效果由对应适配 Mod 提供。
- 需要游戏 0.111.0 与 RitsuLib 0.5.18 或更高版本，仅支持单人模式。
