# Combat Solver v0.26.0 长线搜索性能与 Boss 资源策略更新

## 搜索性能与内存

- 大幅减少长线搜索中的重复工作和临时内存分配；多个公开长线场景在保持路线结果不退化的前提下，搜索时间缩短至原来的约二分之一到十一分之一。
- 改进多核搜索调度，复杂牌序和选牌分支能更充分使用并行计算；并行度上限提高到 `16`，默认仍为 `4`。
- 设置 > 性能新增独立的 NoGC 区域开关，默认启用并使用 `16 GB` 预算；玩家可以单独关闭或调整 `1–256 GB` 预算，不再与性能预设绑定。
- 搜索会根据游戏自身帧率动态减压，减少后台计算对操作流畅度的影响；跨多轮搜索的世界线数量和耗时统计也更加完整。

## Boss 与药水策略

- 第一幕和第二幕 Boss 战后会回复本场战损的 `80%`。智能用药现在优先保留药水：无药路线能够生还时，普通药每瓶至少需要节省 `45 HP` 才会采用，多药按相同标准逐瓶累计。
- 第一幕和第二幕 Boss 的主动卖血额度按战后回复同步调整；求解器可以接受更多能换取胜利或关键长期收益的本场战损，同时始终保留生存底线。
- 第三幕第二个 Boss 及单 Boss 收尾战只判断能否存活，不再为了提高战后剩余生命牺牲药水或更稳的通关路线；第三幕第一个 Boss 仍保留正常血量评价。
- 无药路线会死亡时仍会继续搜索用药解，不受上述保药门槛限制。

## 路线稳定性

- 修复知识恶魔在强制结束回合后可能错误消费选牌计划、导致路线失效的问题。
- 虚空形态只按本回合实际剩余的免费牌次数评价收益，不再把整手牌都当作免费，也不会错误提高 X 费牌价值。
- 进一步减少长线搜索中的状态重建和集中回收，降低复杂战斗后段的等待与内存压力。

本版本继续适配《杀戮尖塔 2》`0.111.0`，需要 RitsuLib `0.5.13` 或更高版本。
