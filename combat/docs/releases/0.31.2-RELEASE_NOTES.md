# Combat Solver 0.31.2

本次更新继续合并玩家贡献，感谢 bingyang1132 和 SlimoonLee。

- **药水价值分档（PR #15，bingyang1132）**：智能用药按药水价值区分消耗门槛，珍贵药水需要更大的收益才会使用，保留救命及手动强制用药规则。
- **第三方 Mod 兼容性提示（PR #18，bingyang1132）**：补充对第三方 Mod 改写出牌行为的检查，未适配时明确提示不兼容；运行中添加或移除相关补丁也会重新识别。
- **战前预测支持（PR #43，SlimoonLee）**：向 Seed Oracle 等伴生 Mod 提供战前预测接口，可用于比较战损、用药及假设战斗样本。预测在独立后台进程运行，支持复用、停止和静音；目前限 Windows 单人模式，需要伴生 Mod 调用。
