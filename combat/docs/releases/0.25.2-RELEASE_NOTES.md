# Combat Solver v0.25.2 批量稳定性修复

## 计算与执行

- 修复部分怪物初始行动在并行搜索时可能触发集合损坏并导致计算失败的问题，兼容安装了行动预测类 Mod 的游戏环境。
- 修复回合准备尚未结束时点击“执行本回合”会提示“当前不是玩家出牌阶段”的问题；执行请求现在会在进入出牌阶段后继续。
- 修复部分复活、随从死亡与跨回合状态未正确同步，导致推荐路线与实机状态不一致或计划外重算的问题。

## 选牌与卡牌

- 修复乱战自动打出无合法候选的选牌牌时计算失败的问题。
- 修复知识恶魔的部分选牌候选不可执行时会让整次搜索失败的问题。
- 修复生命火花、流电、压制、受祝鹿角等效果与开局选牌、生成牌状态不一致的问题，减少筹码、原生选牌和自动执行中止。

## 药水策略

- 修复上一场战斗留下的药水槽策略越过当前药水栏，导致搜索初始化失败的问题。
- 两瓶药中禁用一瓶后，智能搜索最多只会搜索一药路线，不再进入二药梯度。
- 强制使用指定药水时，只有已经满足全部强制指令的完整路线才会显示为可采用结果，避免采用零药中间路线后报策略未满足。

本版本继续适配《杀戮尖塔 2》`0.111.0`，需要 RitsuLib `0.5.13` 或更高版本。
