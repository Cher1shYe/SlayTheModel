# Combat Solver v0.19.0 更新日志

本次更新集中修复原生选牌页面、跨回合自动执行，以及多场复杂战斗中的自动执行中止和计划外重算。

## 选牌与自动执行

- 选择悖论、烘焙手套、赌博筹码和工具盒会先显示原生选牌页面，再开始计算并展示预计选择。求解器会等待玩家点击执行或开启全自动后再完成选择，不会在计算结束时自行替玩家确认。
- “执行本回合”现在会在下一回合的必备工具、暴政等选牌页面交还控制权。玩家可查看页面和预计选择，再次执行或开启全自动即可沿用现有路线继续，无需重新计算。
- 修复咬人卷轴、知识恶魔等战斗中，下一回合或敌方回合的选牌被错误提前处理，导致全自动中止的问题。
- 大卡组的原生网格现在会自动滚动到目标卡牌。修复灵魂枢纽战中选择位于下方的主宰时，自动执行找不到卡牌并停止的问题。

## 稳定性

- 修复环境组装师战斗中，结束本回合时错误提前要求下一回合暴政选牌已经完成，导致自动执行中止的问题。
- 修复打出花样百出并获得必备工具后，求解器在下一回合选牌前错误中止的问题。
- 修复三只咬人卷轴战和知识恶魔战中，下一回合或敌方回合的选牌被错误归入当前回合，导致全自动中止的问题。
- 修复骇鳗的活力在攻击前后结算顺序不正确，导致后续回合计划外重算的问题。
- 修复部分怪物行动在判断存活单位数量时与实机不一致的问题。
- 改善千足虫战斗中的升级牌选择与部署，避免卡牌升级后原生选牌页面找不到计划目标。
- 改善产卵飞虫、实验体、养蜂人、永世沙漏和三骑士等复杂战斗中的牌堆、状态牌、战斗中升级与连续原生选牌处理，减少搜索动作回放失败、自动执行中止和计划外重算。
- 修复满手时生成战利品后，求解器仍尝试使用未进入手牌的卡牌，随后重新计算又发生动作回放失败的问题。
- 改进详细诊断记录。导出的完整问题包可以更准确地记录逐步出牌后的牌堆与敌方状态，便于定位仍未覆盖的重算和回放问题。

## 战斗规则

- 修复主宰与凶恶、地狱狂徒同时生效时的结算顺序。凶恶引发的抽牌和自动出牌现在会先完成，主宰随后再按目标当前的易伤获得力量，与原版一致。
- 修复恶咒施加者死亡后的移除判断，避免受咒卡牌与恶咒状态在后续路线中出现错误差异。
